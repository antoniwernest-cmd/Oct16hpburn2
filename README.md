# RiverReader2

Open index.html to choose one story, The Mystery of the Black Forest, in CVC, Pathway, Excite, Excite/Inspire, Inspire, Explorer A, or Explorer B.

Peter and Luna come to High Park with a new frisbee and unexpectedly arrive on the annual burn day. They investigate the missing wildflowers and return over several weeks to observe new life. The CVC version includes preview words for names and scientific ideas.

The original RiverReader layout, running record, word checks, timer, comprehension ratings, notes, navigation, and Print / Save PDF features are retained. RiverReader2 uses its own local storage keys. The map is a fictional teaching diagram, not a real High Park navigation map.

Burn background: City of Toronto, Traditional & Prescribed Burn:
https://www.toronto.ca/services-payments/water-environment/trees/forest-management/urban-forest-management/prescribed-burn/

Run node verify.cjs to check all seven versions and the reading tools.

Student IDs: choose one of the 20 school-supply pictures before selecting a reading version. Use Change student ID on the home page to switch. Each ID has separate records; the selected ID is remembered on this device and appears in reports. Existing named records remain available through their original student links.
